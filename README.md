# 📊 Excel_Dashboard-BankLoanReport

## 📌 Overview

This project presents an interactive **Bank Loan Analysis Dashboard** built using **Microsoft Excel**.  
It analyzes loan data to track performance, assess risk, and understand borrower behavior through dynamic KPIs and visualizations.

---

# ❗ Problem Statement

Financial institutions deal with large volumes of loan data, making it difficult to:

- Monitor key KPIs like loan applications, funding, and repayments
- Track Month-to-Date (MTD) and Month-over-Month (MoM) trends
- Identify high-risk (bad) loans
- Analyze borrower segments across multiple dimensions
- Make quick, data-driven decisions

---

# ✅ Solution

Developed a multi-dashboard Excel solution to transform raw data into actionable insights:

- 📊 **Summary Dashboard** – KPI tracking & Good vs Bad Loan analysis
- 🌍 **Overview Dashboard** – Trends by time, geography, and borrower attributes
- 📋 **Details Dashboard** – Granular data exploration with interactive filters

---

# 📈 Key Features

- Total Loan Applications Tracking
- Total Funded Amount & Amount Received Analysis
- MTD & MoM Performance Tracking
- Good vs Bad Loan Segmentation (Risk Analysis)
- Interest Rate & Debt-to-Income (DTI) Insights

### Loan Distribution Analysis By:
- State
- Loan Term
- Employment Length
- Loan Purpose
- Home Ownership

# 🚀 How to Use

1. Download the Excel dashboard file from the repository
2. Open it in Microsoft Excel
3. Navigate between:
   - Summary Dashboard
   - Overview Dashboard
   - Details Dashboard
4. Use interactive filters such as:
   - Grade
   - Purpose
   - State
   - Term
5. Explore insights dynamically
